# Move 5: read the scroll

## What it is

A Dockerfile is the recipe for an image. Each instruction adds a layer.

- `FROM`: the base image. Several FROM lines make a multi-stage build. Each stage is its own image, a later stage can `COPY --from` an earlier one, and only the final stage (or the `--target` you pick) ships.
- `ARG`: a build-time variable. It must be declared again in every stage that uses it. `ENV`: a variable baked into the image for runtime.
- `RUN`: execute a command while building. `COPY`: bring files in, from the build context or from another stage or image.
- `WORKDIR`: the directory later instructions and the app start in. `USER`: the user the app runs as.
- `EXPOSE`: documents the port. It does not publish it, that is `-p`.
- `CMD`: the default command, easy to override. `ENTRYPOINT`: the fixed executable, and CMD becomes its arguments.
