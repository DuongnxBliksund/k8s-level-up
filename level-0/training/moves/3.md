# Move 3: the three doors

## What it is

A container is sealed by default. Three flags on `docker run` open a door:

- `-p HOST:CONTAINER` publishes a port. Traffic to the host port is forwarded to the container's port.
- `-e NAME=value` sets an environment variable. The normal way to configure a container without rebuilding it.
- `-v HOST_DIR:CONTAINER_DIR` mounts a host directory inside. Files written there outlive the container.

The app in this folder uses all three. It listens on 8000, greets with $GREETING, and counts visits in /data/visits.txt. Read `app/app.py`.

## Try

```
docker run -d --name move3 -p 8010:8000 -e GREETING=moves -v "$(pwd)/data:/data" k8s-game/training
curl http://localhost:8010
curl http://localhost:8010
cat data/visits.txt
docker exec move3 env | grep GREETING
docker inspect -f '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{end}}' move3
```
